# 标题、属性、主图与详情

制作前查看来源图片和规格。识别“实物是什么、卖哪一款、一次卖多少”，再选择最能帮助买家判断的表达。来源缺失的信息可继续查找；不能把合理猜测直接写成确定的商品事实。

## 标题

使用目标市场自然的商品名称，优先说明品类与最有区分度的规格，再补充真实用途或关键特性。以准确且容易辨认商品为目标，不机械堆词。品牌、材质、容量、适用型号、套装件数采用可确认来源；避免将供应商营销词直接翻译成客观保证。

同一商品的不同 SKU，标题中的容量、颜色、数量与销售组合一致。品牌缺失时按平台支持的方式表达，不创造品牌。

## 属性

按当前类目和字典填 Ozon 字段。确定的单位换算、字典标识匹配和默认值由程序完成；需要理解商品含义的选项由 Agent 选择。平台报错后查询对应字段，不为每次小修改重复拉全量类目。

素材或文案只给出了模糊描述时，查原始规格和清晰图片。若仍不能决定关键属性，保留具体问题；不要用“常见值”冒充该商品的数据。

## 主图和配图

选取能清楚识别本 SKU 的真实商品表现，确保主体外观、颜色、附件、套装件数与销售内容一致。对生成或编辑的图片检查实际输出，不依靠生成提示词判断结果。

版面重点服务于识别商品和理解差异。无需把所有卖点都挤入主图；尺寸、用途和细节可以分到配图。不能通过生成图增加未包含的配件，或让质地、结构、功能与实物不符。多规格共享图片时，检查它是否仍适用于每个使用它的 SKU。

## 详情

围绕买家选择商品所需的信息组织：适用情境、可确认特性、规格、包含物和使用说明。可按商品需要选择顺序与形式，不强制凑齐固定段落。尺寸与数量清晰，性能与兼容性表述有来源。

图片、标题、属性和详情共同表达同一销售商品。共用详情不写与某个变体冲突的信息；必须区别的内容放回变体对应部分。

## 完成时

实际看一次成品，修正发现的问题。只检查内容结果，不再输出自证清单。随后保存/提交确定版本，由统一审核层独立检查必要问题。
