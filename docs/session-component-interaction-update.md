## 选中商品作为聊天附件

“附加到当前聊天”生成 `Hallmark-已选产品-N项.json`，通过 DSH 原生附件注册和 `inputActions.addAttachments` 加入输入区。正文保持原样，用户补充要求后手动发送。附件保存稳定商品 ID、数据源和来源会话信息；附加本身不发送消息。

重复点击同一选择会去重；用户移除附件后可以重新附加。附加失败释放新建草稿，成功后的上传、移除、重试和发送交给 DSH。原生发送后的文件会给 Agent 一个可读取的路径，Agent 需用文件工具读取 JSON；相关规则已写入 `APP_INSTRUCTIONS`。

兼容适配器使用 DSH 0.2.0-rc.2 已导出类中的 `createDrafts/releaseDraftAttachments`。这两个方法未纳入 `IConversation` 窄接口，因此运行时检测能力，不支持时给出提示，不回退正文。Manifest 已声明 `@deepseek-ai/dsh-client-ui-conversation` 注入。

源码、接口证据和详细验收范围见 [附件说明](selection-attachments.md)。未执行真实上传或发送；原生体验仍待安装后核验。

## 管理本会话组件

右侧列表新增“管理”，每项可重命名或“从本会话移除”。移除使用行内确认，明确不会删除保存的组件、模板、入口和业务数据。重命名也仅影响会话临时视图。

移除后保留所有权标记，本会话详情、数据读取、后续编辑和保存均失效。其他会话不能猜 ID 接管；原会话可明确重新生成该 ID。已保存设计仍可从组件库重新打开。

成功事件限定 `sessionId/viewId`，右侧被移除详情回到列表，已打开工作台标签重新读取后显示不可用。请求失败保留编辑状态；网络结果不明确时提示重新读取确认。会话切换或卸载后的迟到结果不会更新新会话。

改动涉及客户端列表、桥接 API、会话视图注册表、独立服务及 Host 代理端点。不能只更新 Client 就获得完整管理能力。
