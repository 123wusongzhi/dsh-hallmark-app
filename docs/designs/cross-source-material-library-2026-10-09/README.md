店铺统一在顶部选择。仓库和日期只在选中信息需要时出现，并作用于相应数据。后台应按同一店铺、可确认的商品身份关联：分仓库存先按所选仓库处理，期间指标先按时间范围汇总，避免多条明细重复扩展商品行。无法关联的值保持缺失，不填零。需要不同业务粒度的字段应先提供明确汇总方式，不能任意拼接。

这是对原先“一个表格只选择一个数据源”的交互调整：用户面向业务字段，平台/Agent 维护关联与汇总规则，并将组合保存为可复用定义。具体接口的授权、币种、时间范围和可关联性仍需实际验证。
