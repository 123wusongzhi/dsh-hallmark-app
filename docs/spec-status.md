# 全规格追踪与用户覆盖要求

基准：[原规格](../../DSH应用插件_spec_doc.md)。原文保持不变；本表不是“全部已验收”声明。

## 2026-10-06 · 0.2.0 开发更新

本轮具体证据见 [交付与加载检查](release-0.2.0.md)。已完成 task19 类目工具、采集查询快照、打开保存组件草稿/CAS 更新、置顶入口、表格选择附加原聊天、TanStack/Recharts/shadcn Table 与 json-render core 接入。连接修复后全量 373 项 Node 测试通过，此前 47 项隔离浏览器断言通过。已官方安装并重开 DSH；独立服务实际 0.2.0/25 工具、4280 来源只读返回 367 采集产品/2 店铺。原生 Host 自报版本、GUI/平台完整验收未完成。Board 缺少旧分派 `/api/assignments`，写链需另适配。以下历史矩阵中的“类目尚未 Core 接入”“23 工具”和“4173 离线”仅适用于旧检查点。原 React runtime 因宿主 React 18 不兼容而未接入，未修改 DSH 核心。

## 判定与优先级

用户后续要求高于冲突原文，其余照原规格实施，不以 MVP 或合成测试替代最终验收。

- 原 DSH 导航 → 常驻应用列表 → 工作台，初始不选应用；仅真实 Hallmark，无装饰性未来应用、弹窗或复制聊天。
- 单击打开工作台，不隐式激活聊天；双击、右键启动聊天、进入聊天走原精确会话并激活。此项覆盖 M11/M12 的“入口单击即激活”。
- 工作区标签：固定工作台、组件按 viewId 去重、关闭、＋临时设计、切换保留未保存草稿、键盘导航。
- 原聊天使用现有原生右侧栏“本会话组件”；输入区入口、工具卡侧栏查看、在工作区标签打开。不得替换原 rightbar.session 或新造聊天。
- 会话临时组件只认可信生成归属；已保存设计仍是个人 profile 配置。历史读取不要求应用激活，但跨会话临时组件不认领、不回退全局。
- 默认临时、不自动保存；真实写必须另有当轮明确业务指令、范围、数值与来源。用户要求开发完整规格不是真实调价/库存/上品授权。
- 保留用户的条件 description 修复；构建及注册前严格 JSON 守卫，不能再次破坏普通聊天工具头。

“实现/合成”表示源码与隔离测试存在；“原生”须运行时实际加载证据；“真实”须真实数据或平台记录。截图使用隔离框架，不能冒充现有 GUI 实测。

## 核心业务覆盖清单尚未全部完成

原规格 §4 要求 H1 盘点后的“其余核心能力”补清单，不能把目前23工具当作完整覆盖：采购成本更新、促销报名/退出/配额、原四工具WorkPlan/素材交付及命名价格规则仍有接口/工具覆盖缺口。类目六模式与商品归档的薄适配已实现并有29项新增mock测试；正式工具/Core仍未接入，不宣称这些已可由聊天执行。活动价接口存在不等于支持 price-only；无 Task CNY 普通售价也不等于通用无商品 Task。逐项以真实来源合同和显式用户业务范围实施，不能新增不受授权的默认写或伪造完成标志。

## 仍需人或原项目合同的输入

1. 实际启动原 Hallmark 后端及需要时显式提供原 operator token 环境配置；不能读取其 human-token 或 Ozon credential 文件。
2. 用户指定真实测试店铺、商品、采集 item/SKU、明确价格/币种/仓库/库存；本轮开发请求不等于真实业务授权。
3. 官方安装更新要求重启时，由用户重启当前 DSH；不能强杀正在使用的 GUI。
4. 48h 连续运行及 Windows 登录自启是单独可选操作/验收，不擅自注册系统计划任务。
5. 通用无商品店铺 Task、price-only 活动接口、可信命名规则、source stock/query 范围能力须真实合同支持；不能捏造 API 或 dummy 商品绕过。
