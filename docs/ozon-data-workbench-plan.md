# Ozon 数据接口与独立店铺上下文实施方案

方案日期：2026-10-08。最终验收：2026-10-09（北京时间）。状态：已实现并在独立正式 Web 配置安装、验收完成。

## 已确认需求

1. 将以下 10 类自有店铺运营数据全部封装，不包含市场选品或竞品接口。
2. Bill、Helen 只作为店铺选项。数据源定义、中文字段、组件列配置共用，不复制成两套目录。
3. Agent 复用平台现有店铺授权完成适配；凭据留在原平台。封装完成后保存可复用定义。
4. 工作台顶部选择店铺；素材库预览继承或显式选择店铺。切换店铺保留组件布局与字段配置，清除旧分页、商品选择、联动状态和过期响应。

## 契约

### 原平台与只读网关分别部署时的连接

同一个 Hallmark 连接可以配置两个服务地址，不为 Bill、Helen 或新数据接口创建重复连接：

```json
{
  "baseUrl": "http://127.0.0.1:4280",
  "ozonDataBaseUrl": "http://127.0.0.1:4281"
}
```

`baseUrl` 保留原平台店铺列表、任务、旧查询、健康检查和全部业务写入。可选的 `ozonDataBaseUrl` 只承接 `/api/stores/:storeId/data/read` 与 `/api/stores/:storeId/data/order-weights`，供 10 类 Ozon 数据能力和跨接口组合使用；不向只读网关转发原业务操作令牌。省略时，这两条数据路由仍使用 `baseUrl`，兼容合并部署。

两个地址采用相同校验：仅允许 HTTP(S) 的 `127.0.0.1` 或 `[::1]` 原点，可带端口；拒绝域名、凭据、路径、查询参数和片段。网关继续复用原平台店铺授权，连接配置不保存店铺 API 凭据。

已有连接应通过 `PATCH /v1/connections` 的受控更新提交完整新配置和 `expectedConfigRevision`；配置版本递增后刷新连接客户端和缓存。仅修改启动种子 `connections.json` 不会覆盖数据库中的现有连接。更换地址后仍保留原 `connectionId`，数据目录与组件引用继续共用。

### 数据契约

- 平台侧增加店铺级只读数据网关，不依赖上品任务。只允许登记的路径、方法与受约束参数；包括只读订单报表生成，排除改价、库存更新和订单操作。
- 数据能力采用平铺业务参数及统一 `items` 输出，分页游标绑定店铺和筛选条件。保留日期区间、来源时间、币种、单位、空值和错误。
- 数据源 ID 为连接与业务类型的组合；`storeScoped: true` 表示运行时注入工作台店铺上下文。定义中不保存店铺编号或名称。
- 工作台保存 `context.storeId`，组件保存数据源引用和展示配置；店铺进入实际请求和缓存身份，不能跨店复用结果。
- 内置目录登记与实店验证分开记录：未验证、失败、有记录验证和空集验证均如实展示。Agent 自定义数据源仍须通过验证后登记。
- 原按店铺保存的数据源保留历史版本用于追溯，当前目录迁移为共享定义；现有组件迁移引用且保留布局。
- 通用“数据表”素材支持这 10 类中文字段，不要求订单、财务或库存伪装成商品/活动字段。

## 实施步骤

1. 更新需求、类型、上下文和目录契约。
2. 平台网关、10 类数据能力、店铺选择 UI 并行实现。
3. 集成中文字段目录、通用表格、旧引用迁移和按店铺隔离的读取。
4. 验证权限失败、空集、分页、异步报告、切店竞态和旧配置恢复。
5. 用现有店铺授权执行只读验收，记录每个能力的真实结果；权限或平台返回限制单独标明。
6. 构建并安装至本任务独立运行环境，完成工作台与素材库浏览器验收。不得停止其他任务的 4195/36994 环境。

## 验收标准

- 目录包含 10 个 Ozon 业务数据源，同连接下不因店铺增加而重复。
- 相同组件在切换 Bill/Helen 后请求正确店铺；旧响应不能覆盖新店结果。
- 所有面向用户的字段有中文说明；订购件数不冒称结算销量，模型利润不冒称实际结算利润，申报重/体积重不冒称物流实重。
- 日期、分页、金额缩放、缺失值和来源保留，不能截断后宣称全量。
- 应用端与浏览器不保存平台 API Key；平台拒绝未登记路径及写入方法。
- 所有新增适配具备自动化行为验证；实际可用性以实店调用结果为准。

### 兼容与数据语义

- 原 Bill/Helen 固定店铺定义迁移为共享定义；旧历史版本仍保留，当前目录的旧 ID 退休。大小写不同的店名也能清理；实例列名、布局、顺序与筛选日期保留。
- 旧只读活动能力优先使用店铺网关，仅当本地网关明确不存在时回退旧路径，已有组件仍可读取。
- 价格保留原币种；普通售价、当前卖家价、订单单价分开。财务保留原币种与费用类型，不把记账金额称为利润。
- 实重只接受报告中核实的单 SKU 单件记录；多件、混装和未知重量记录注明跳过。
- 空数据、生成中的报告、权限或网络失败分别显示；财务跨日查询即使当天为空也保留次日游标。
- 服务端分页和报告记录使用真实数据库持久化，并按连接配置版本与店铺隔离；重启后可继续查询同一待生成报告。
