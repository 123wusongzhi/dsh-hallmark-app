## 发现与修复

1. **P2：异常健康响应被误判正常。** 探针将 null、数组、缺少 status 的对象归一化后接受为健康，可能显示错误的恢复状态。现在必须收到字符串 `status: ok`；结构异常返回 `RUNTIME_INVALID_RESPONSE`，其他状态保留不健康错误。
2. **P2：新环境缺少浏览器测试数据时无法启动审计。** 原审计静态导入 Git 忽略的 `browser-data.ts`，只设置有效的 `DSH_REAL_CORPUS` 仍会模块缺失。新增离线生成入口，审计自动补建缺失文件；已有文件不静默修复，继续发现篡改。显式 `npm run prepare:test-data` 可在更换快照时重建。回归验证原始数组和图片 SHA-256。
3. **P2：新增测试未分类阻断测试入口。** 补齐 5 个文件的真实业务／基础设施分类和理由，保留未知测试拒绝规则。
4. **P2：关联 cursor 解码为 null 时抛内部异常。** 在访问 cursor 字段前验证对象结构，统一拒绝 null、数组和基本类型，返回 `COLLECTION_CURSOR_INVALID`；覆盖范围及数据版本检查保持生效。
