# candidate56：本次会话与我的收藏

右侧组件区域有两个常驻入口：「本次会话」「我的收藏」。大组件在独立、可关闭的标签中打开；再次点击同一组件会切换到已有标签。关闭详情标签只改变当前界面，不删除或关闭 Runtime 工作副本。

## 页面

- 本次会话：最新制作中的组件以一张宽卡呈现，其余组件为轻列表。目录只读元数据，不挂载所有组件，也不等待业务数据。
- 我的收藏：仅展示用户主动点亮星标的组件；当前本地 profile 保存收藏引用，跨聊天可用。收藏与素材库、工作台布局分别保存。
- 制作状态：显示「正在打磨，请稍候」，并区分编辑、校验失败、暂停、就绪等实际状态。已有预览在编辑期间仍可查看。
- 收藏动作：已确认的临时组件经过既有保存回执和版本检查后再收藏。已保存的素材直接收藏，不重复保存。取消收藏不删除组件。
- 失败处理：收藏响应丢失时回查原结果，保存回执不确定时不重复提交。失效连接的收藏仍可取消。

## 宿主与数据边界

DSH 0.2.0-rc.2 的公开原生侧栏接口不提供固定不可关闭标签。因此沿用唯一原生「组件」容器，在其内部实现两个常驻入口及详情标签；不依赖私有 DOM 或更改宿主。

收藏仅存 componentId 和创建时间，读取时点查组件与连接。会话创作状态使用 ownerSessionId/viewId 索引一次投影查询，不扫描源码和业务缓存。切换聊天隔离目录、请求和标签，隐藏详情不会继续挂载其数据桥。

类型检查及正式打包通过。360/800 像素下的会话、收藏、等待态共 6 个实际 React 场景通过，每个场景包含 62–65 条检查；入口不读取业务数据、不挂载 iframe，标签关闭与重复打开、隐藏后恢复、会话隔离均已覆盖。该视觉验收使用隔离测试数据，并非原生桌面截图。

全仓首次执行 1140 项，1134 项通过；6 处回归涉及侧栏目录重复读取及等待文案断言，修正后对应 7 项重跑全部通过。快速切换预览新增 5 项及关联生命周期、侧栏回归 10 项通过。另补首次打开素材库的导航回归，防止入口被工作台初始化覆盖。
