# 关联总览

入口：应用 → Hallmark → 关联总览。选择经营连接和店铺后，可在“从店铺商品查看”和“从采集箱查看”之间切换。

- 店铺方向显示销售货号、平台商品编号、在售状态及采集来源；展开可查看来源 SKU 与组成数量。
- 采集箱方向显示该采集商品在所选店铺中关联的销售商品及各自状态。点击关联商品可切换方向并精确定位，点击“返回全部商品”解除定位。
- 支持名称、货号、采集编号与 SKU 搜索，以及关联状态和在售状态筛选。每页 30 件，筛选在分页前执行，关联统计覆盖当前搜索/定位范围，非仅本页。
- 打开页面时读取状态；“刷新关联与状态”主动更新店铺状态和采集目录。分页、筛选不强制重新抓取业务源；不定时轮询。

来源关系只使用保存的商品 ID、来源 SKU 和采购组成，不按名称、图片或货号前缀猜测。明确的空来源记录显示“未关联”；缺少来源字段、来源不一致、历史导入失败、目录未读全等情况显示“关联未确认”。采集方向只有目录完整、状态有效且历史来源均可确认时才能断言未关联。读取失败显示警示，已知结果不是完整目录。

店铺商品包括平台目录中已上传的商品（在售、缺货、待审核、失败、归档等）和已保存采购绑定的商品；本地尚未上传的上品草稿仍在经营操作页面查看。超过现有五分钟有效期或本次同步失败的在售观察显示未确认；保留观察时间，不把旧状态当作当前在售状态。

本页只读，不建立、更改或删除关联，也不提交商品修改。查询通过 Host 的 `associations` 资源到本地 Runtime 的 `/v1/associations`，沿用本机服务鉴权，并检查店铺归属与经营连接启用状态。
