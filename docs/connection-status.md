# 应用连接检查与一键修复

应用工作台显示应用服务节点及当前配置的 Hallmark 数据接口状态。打开工作台时检查一次，也可点击“检查连接”；不定时刷新业务数据。只有节点正常且数据接口检查通过才显示“已连接”。节点响应异常或数据接口不可用时显示“连接异常”，节点连续检查失败时显示“节点未连接”。显示检查时间及失败原因；界面请求失败后不会保留“已连接”结论。

“一键修复（重启）”通过 Host 的受管理启动清单工作。服务仍可响应时先请求带鉴权的停止接口，服务完成关闭后由现有监督器重新启动；服务已退出则直接尝试启动。并发点击合并，沿用端口检查、跨 Host 锁及重复进程保护，最多等待 45 秒恢复，随后重新检查数据接口。正在处理其他 HTTP 请求时拒绝重启并提示稍后重试。

重启范围是本地 Apps Runtime；不重启外部 Hallmark 后端或整个桌面应用。没有有效的安装器启动清单时禁用重启。无法响应停止请求的进程不会被按端口强杀，界面显示失败结果。业务源故障、凭证或配置问题可能在重启后仍存在，只有复查通过才显示连接正常。

接口：`GET /api/dsh-apps?resource=connectionStatus`、`POST /api/dsh-apps`（`action: restartRuntime`），以及仅限本机并使用服务令牌鉴权的 `POST /v1/runtime/restart`。
