# 应用导航任务地图与中断恢复

基线：`fd95bc22929bfbfa850e0312357322578287a10c`。本次仅调整应用工作台的数据组件生命周期，不新建聊天系统，不改变原生 `@`、多会话归属、业务提交或规则。

## 真实入口盘点

| 用户想完成的事 | 已有路径与状态所有者 | 当前发现 |
|---|---|---|
| 上品 | 原聊天 `@ Hallmark` 准备资料；应用 → 经营操作 → 上品动作/批次 | 顶层“经营操作”没有直接告诉首次用户它包含上品。批次页承接审核/提交，不宜另造平行提交入口。 |
| 调价、库存、促销 | 应用 → 经营操作 → 对应动作；经营设置维护物流与定价规则 | 操作与规则是不同对象，必须保留已保存/未保存/已提交边界。 |
| 看商品、订单、库存等数据 | 工作台已有卡片；首次从添加组件进入模块与数据源配置 | “添加组件”后页面叫“素材库”，实际内容是数据模块/预设，容易与商品图文素材混淆。 |
| 重用保存结果 | 工作台“我的组件” → “我的组件与模板”标签 → “共享组件库”区域 | 同一库有三个名字；不需要增加第四个入口。 |
| 继续制作组件 | 原聊天与右侧栏“本次会话”，或应用工作台的已打开工作副本标签 | 原会话拥有创作与发送；返回当前聊天按钮已经存在，应沿用。 |
| 继续查看数据 | 工作台已打开的数据卡片标签 | 原实现保留标签但卸载详情，返回后搜索、页码、选中状态丢失。本次修复此项。 |
| 恢复关闭内容 | 工作副本：“已关闭工作副本”恢复；数据卡片：从工作台重新打开 | 前者有持久工作副本与恢复回执，后者仅关闭本地标签。不能把两者伪装成同一种业务进度。 |
| 维护采购对应关系 | 关联总览 | 可考虑明确为“采购关联”；不应合并到素材/组件库。 |

## 优先级与文案建议（设计提案，未宣称已验证收益）

1. P0：先保证现有“已打开任务”标签是真正的继续入口，而不是带同名标题的新页面。本次已实现并做 React 回归。
2. P1：统一组件层概念。保留“添加组件”动作，模板目录叫“组件模板”，编辑态叫“配置组件”；保存库统一“已保存组件”，副文案说明包含模板。不要把上品图片素材和组件模板都叫素材库。
3. P1：业务主入口保持一个，可用“商品操作”，旁边说明“上品 · 调价 · 库存 · 促销”。这比新增四个平行批次页更符合当前共用批次/审核模型。最终命名需和各业务流程验收一起确认。
4. P1：依赖所选店铺的页应显示同一个当前店铺上下文，并能在缺少店铺时直接回到现有选择器；不要只留“先去工作台”的说明。
5. P2：左侧应用标题与标签栏各有一个“新建组件工作副本”加号，可收敛到一个明确命名的入口。“添加组件”应保留为使用已有数据模块，与让 Agent 创作新组件分开表达。
6. P2：统一状态文字，保留各自事实来源。数据读取用读取/暂停/失败；组件制作用制作/预览/已保存；业务操作用草稿/审核/提交/平台结果待核查。不能把 pending/unknown 简化成完成，也不应编造统一百分比。

## 本次实现

- 最近访问的 3 个工作台数据实例保留 React 状态；首页仍只读取目录元数据，不挂载全部数据卡片。
- 切换到工作台、其他标签或原聊天时，隐藏实例停止刷新计时器并取消在途读取；已经成功的快照和本地搜索、排序、页码、产品选中保留。
- 同一身份返回时，未完成只读查询按原参数恢复；已完成且新鲜的快照不因切标签重新读取。
- 超过 3 个时释放最久未访问实例，但保留标签入口；再次打开时重新读取。关闭标签立即释放，不修改持久工作台卡片。
- 应用、原聊天、店铺变化时释放原作用域的实例。数据源身份变化仍沿用原身份清理逻辑；旧响应不能覆盖新状态，权限失败不使用旧数据兜底。
- 未改变原生聊天、侧栏发布授权、工作副本保存/关闭/恢复协议。

## 可重复对照

`test/plugin-apps/workspace-resume.test.ts` 实际打包运行生产 `AppsWorkspace → WorkbenchBoard → WorkbenchInstanceView → ViewRenderer/ProductTable`。第一组只隔离外层应用目录；第二组直接运行真实 reader/renderer。测试数据是仓库已授权公开冻结来源的 UI 派生值，网络回执与延迟故障在本地隔离。

| 场景 | 基线实际结果 | 候选实际结果 |
|---|---|---|
| 输入搜索 → 工作台 → 原数据标签 | 搜索从 `not-a-product` 变成空字符串，断言 red；需要重新输入 | 搜索保留，fresh snapshot 的数据读取次数仍为 1 |

| 选中商品 → 暂离 → 返回 | 本轮未单独采集基线选中状态数值 | 真实产品列表选中与关联 SKU 身份保留 |

| 跨 app/store/session | 既有边界仍需保持 | 新测试覆盖作用域清理、无误发旧任务读、403 清旧数据、旧响应无效 |
