# 上品资料精简与程序自动定价

日期：2026-10-13。修改当前工作区，未安装到运行中的 DSH，未向真实 Ozon 提交商品。

## 行为

- `hallmark.listing.prepare` 不调用报价计算，不返回逐销售行 `quote`。旧准备快照的续页同样移除报价，但不改写历史证据。
- 创建/修改草稿传 `pricing.mode:"automatic"`，省略 `payload.price`，由既有定价程序读成本、包装及店铺规则并写入售价。提交及语义审核后的复核继续使用当前规则；自动模式不因已有计算价格而变成手动模式。
- 上品普通草稿返回及 Agent 摘要保留最终价格、定价状态、配置版本、问题和警告，不重复返回详细报价分解。内部完整证据仍保存；显式 `get(includeEvidence:true)` 和专门试算能力仍可查看详情。调价等其他经营动作不变。
- 重复包装公共字段及完全相同的类目内容采用本页 `shared` 表，只有实际减少 UTF-8 JSON 字节时才使用。无损共享，不是文本截断或 gzip；数字、缺失值、成员身份、包装版本和约束原样保留。

## 共享结构

若销售行 `packaging` 有 `sharedRef`，先读 `page.shared.packaging[sharedRef]`，再合并该行的 `version` 和 `missing`。若 `categories[itemId]` 有 `sharedRef`，从 `page.shared.categories[sharedRef]` 取得该商品本页的类目内容。引用只在当前页有效；每页自带所需定义。无 `sharedRef` 的内容仍是内联原结构。不要把共享引用写入 Ozon payload。

分页仍保留原 14,000 字节预算、销售行数限制和 continuation；完整性标记仍表示准备结果分页完成，嵌套商品资料的独立续读没有取消。调用说明、Skill 和生成 SDK 文档同步更新。
