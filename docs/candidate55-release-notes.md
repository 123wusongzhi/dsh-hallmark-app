# candidate55 发布说明

日期：2026-10-09。Bundle、Host 插件与 Runtime 版本均为 `1.0.0-candidate.55`，数据库 schema 仍为 4。本版已覆盖安装并核对正式 DSH Desktop profile；源码延续 candidate36 分支。

## 工作台与组件

- 工作台以紧凑的缩略图和标题展示常用组件。目录只读取元数据，点击后在应用顶部独立标签页打开完整内容，再次点击定位已有标签。
- Agent 组件在聊天侧栏及应用预览顶部直接提供“添加到工作台”。当前展示先按原验证与版本冲突规则保存，再固定该版本；“我的组件”可直接添加已保存版本。
- 工作台引用和素材库组件独立。同一保存组件最多一张入口卡，重复添加幂等；移除卡片不删除素材库、源码或历史。已有预览使用认证缩略图，没有预览时显示示意图。
- 标签关闭按钮为 36×36 像素，单击关闭并保留内容。失败保留原标签，迟到回执不会抢走新选择；源码工作副本可从“已关闭工作副本”恢复。
- 同聊天、组件版本及数据配置的普通打开复用原工作副本；继续编辑使用原工程。不同店铺、历史版本、显式独立副本继续保持隔离，不绕过保存冲突。

## 数据与交互

- Ozon 数据目录按平台能力和字段共用，店铺在外部选择。封装 10 个经营数据接口及跨接口字段组合，业务名称、单位和来源映射为用户可读字段。
- 商品采购对照表包含商品图片、销售与采购规格、商品与采购网址、采购价、售价、物流方案和参考利润率，并提供搜索。
- 数据在后端形成当前店铺及查询范围的完整快照，前端本地分页、搜索和排序。每次读取优先使用上次成功快照，有效期 15 分钟；到期或手动刷新在后台更新，完整成功后替换。
- 并发刷新合并，临时失败及限流保留快照和原时间。店铺、查询参数及授权版本隔离，授权撤销后不继续提供旧数据。
- 物流渠道从接口获取并匹配。采购价、重量、费用或运价缺失时标为待补充，不将未知值填零，也不将试算当成平台业务写入。
- 统一用户偏好直接进入 Agent 创作指南；源码组件 SDK 区分首次加载与后台更新。
