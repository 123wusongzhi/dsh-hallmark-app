# 商品分页与当前交付范围

2026-10-08：按用户要求暂时屏蔽附加到聊天，当前只交付商品展示、当前页搜索、刷新与分页。

商品源码示例移除勾选与附加按钮；Apps 原生 Host 在 getContext 中声明附件不可用，并拒绝 attachSelection。底层选择协议保留以兼容历史数据，但不开放原生附加。已有归档组件的 HTML 不会被自动重写，旧按钮需通过正常编辑、构建和发布更新后移除。

列表统一使用 useApps.readBindingPage。Runtime 保持绑定查询条件和页大小，按服务端 cursor 读取；payload/resources/revision 一起返回。同一组件实例的 getData 返回当前页，其他实例与 Agent 普通读取的基础快照不随翻页改变。删除附件功能不意味着 Agent 自动看到用户当前页。

示例只在读取成功后更新页码，失败保留原页面；请求期间禁用分页与刷新，并以同步 pending 标记避免连续点击发出重复请求。刷新回到基础查询第一页并清空游标历史。基础绑定应不带初始 cursor。

验证：分页服务覆盖 338 条记录完整遍历、末页、回看、实例隔离、过期响应和失败保留；隔离 React 测试覆盖行内容与页码同步、连续点击、失败重试、刷新及无附加控件。此次分页测试 5 项通过；另有原生展示与 Agent 指引相关测试通过，类型检查和 diff 检查通过。
