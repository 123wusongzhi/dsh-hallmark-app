# candidate70 发布说明

日期：2026-10-10（北京时间）。Bundle、Host 插件与 Runtime 均为 `1.0.0-candidate.70`，数据库 schema 保持 4。基于 candidate69 修复采集箱选品时“未上过”和“关联未知”混用的问题，已安装正式 DSH Desktop。

## 改动

- 新增目标店铺的 `listingRecord` 筛选：`found` 有记录、`not_found` 查询完成但无记录、`unavailable` 暂不可查。无记录可作为新上品候选，不承诺历史上绝对没有同款。
- 按当前商品和店铺判断。其他历史商品缺少采购关联，不再阻止当前商品进入候选；草稿、组合上品成员、失败及归档记录均保留。
- 查询未完成时，新记录筛选返回 `total=null`、已知匹配数量和统一原因；真正没有匹配时返回 `total=0`。旧筛选含义不变。
- 表格增加店铺和上品记录筛选，明确完整快照或已加载范围；上品准备提供已有记录摘要。工具说明、生成 SDK 和上品 Skill 同步更新，不增加审核步骤。

## 验证与边界

- 77 项相关自动测试通过，覆盖跨店铺、草稿、组合、归档、失败、同步异常、历史记录首次迁入失败及恢复、分页、零结果与表格交互。类型检查与打包通过。
- 正式 DSH 安装的 65 个产物与构建清单一致；实际 Host 客户端、运行中 Runtime、数据库和安装后就绪检查通过。
- bill 店铺实际只读查询：318 个采集商品无本店上品记录，50 个有记录；其中 11 个包含归档销售关联，8 个包含失败销售关联，后两者可能重叠。翻页无重复，真实零结果明确返回零，旧筛选行为保留。
- 本轮未提交 Ozon 商品写入，未重跑完整 Agent 上品会话；不把接口验证表述为完整会话验收。
